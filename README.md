# Raj Fitness Editable PWA

This version keeps the current 9-day programme but lets you edit it inside the app.

## New editable features
- Add exercises to any day
- Rename or replace exercises
- Change rep range, RIR target and rest period
- Reorder exercises
- Remove exercises without deleting historical workout logs
- Rename sessions
- Convert a day between strength and recovery/rest
- Reset programme to the original 9-day plan without deleting history

## Windows / VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install Live Server.
4. Right-click index.html and choose Open with Live Server.

## iPhone
Host the folder on an HTTPS static website, open that address in Safari, then Share > Add to Home Screen.

## Data
Workouts, body logs and programme edits are stored in the browser using localStorage. Use Settings > Export JSON regularly for backups.
